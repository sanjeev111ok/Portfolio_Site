# Sanjeev Shrestha — Portfolio

SSR Next.js portfolio with light/dark theme.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- lucide-react

Primary: `#4C1D95`

## Develop

```bash
npm install
npm run dev
```

## Content

Edit `src/data/profile.ts` for copy, links, experience, and projects.

Optional env:

```bash
NEXT_PUBLIC_SITE_URL=https://www.sanjeevshrestha200.com.np
```

## Build

```bash
npm run build
npm start
```
